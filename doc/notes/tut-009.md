# Summarize this video

الفيديو يشرح كيفيّة بناء طبقة **Vector DB** في مشروع mini-RAG باستخدام Qdrant، مع تصميمها كـ “factory” قابلة للتبديل مستقبلًا.[^1_1]

## هدف الحلقة

- بناء أول عنصر من عناصر الـ Vector Database داخل نظام mini-RAG، بحيث يمكن لاحقًا استبدال Qdrant بأي Vector DB أخرى دون تغيير باقي الكود.[^1_1]
- ربط هذه الطبقة بخطوة الـ indexing السابقة التي تنتج embeddings، تمهيدًا لمرحلة الـ semantic search في الحلقات القادمة.[^1_1]


## تصميم الواجهة (Interface)

- تعريف `VectorDBInterface` كـ ABC فيها دوال أساسية: `connect`, `disconnect`, التعامل مع الـ collections (create, delete, exists, list, get_info).[^1_1]
- إضافة دوال إدخال البيانات: `insert_one`, `insert_many` مع دعم `metadata` و`record_id`، بالإضافة إلى `search_by_vector` مع `k` كأقصى عدد نتائج.[^1_1]


## شرح أنواع قواعد البيانات

- توضيح الفرق بين قواعد بيانات engine-based (مثل Mongo, MySQL) التي تحتاج خدمة مستقلة تعمل في الخلفية، وبين file/memory-based التي تعمل كملفات على القرص بدون engine منفصل.[^1_1]
- الإشارة إلى أن Qdrant في هذه المرحلة تُستخدم بطبيعتها الأقرب لـ file-based عبر Python client، مع التأكيد على أهمية اختيار مشروع نشط ومجتمعه قوي.[^1_1]


## تطبيق Qdrant كمزوّد (Provider)

- إنشاء `QdrantDB` التي تُطبّق `VectorDBInterface` باستخدام Qdrant Python client، مع إعداد `distance` (مثل cosine) و`vector_config` باستخدام `embedding_size`.[^1_1]
- تنفيذ منطق: التأكد من وجود الـ collection قبل الإنشاء أو الحذف، استخدام `upsert` في Qdrant مع `payload` يحتوي النص الأصلي والـ metadata، ودعم الإدخال على دفعات باستخدام `batch_size`.[^1_1]


## Vector DB Factory وتهيئة المسارات

- بناء `VectorDBProviderFactory` شبيه بـ `LLMProviderFactory`، يستقبل config (نوع الـ DB، المسار، distance method) ويعيد الكلاس المناسب (حاليًا Qdrant).[^1_1]
- إضافة منطق في `BaseController` لإنشاء مجلد عام للداتابيز (مثلاً `databases/`) وتوليد المسار الكامل لكل instance، مع ضمان وجود المجلد وإهماله في `.gitignore`.[^1_1]


## ما الذي يتبقى للدرس القادم؟

- في نهاية الفيديو يوضح أن كل المكوّنات أصبحت موجودة لكن كل جزء ما زال “لوحده”، والخطوة التالية هي ربطها: استخدام LLM factory + Vector DB factory مع الـ indexing pipeline لتنفيذ أول عملية semantic search كاملة.[^1_1]

## إيه اللي بيحصل في الحلقة؟

- الحلقة بتبني طبقة **Vector DB** في mini‑RAG، وتعرّف Interface عام + Provider لـ Qdrant + Factory لاختيار الـ provider من الـ config.[^2_1]

## خطوة 1: vector_db_interface.py (شرح عام)

الفكرة المنطقية اللي في الفيديو (هنا pseudo‑code قريب جدًا من اللي عنده):

```python
from abc import ABC, abstractmethod
from typing import Any, Dict, List, Optional

class VectorDBInterface(ABC):
    @abstractmethod
    def connect(self) -> None:
        ...

    @abstractmethod
    def disconnect(self) -> None:
        ...

    @abstractmethod
    def collection_exists(self, collection_name: str) -> bool:
        ...

    @abstractmethod
    def list_collections(self) -> List[str]:
        ...

    @abstractmethod
    def get_collection_info(self, collection_name: str) -> Dict[str, Any]:
        ...

    @abstractmethod
    def delete_collection(self, collection_name: str) -> None:
        ...

    @abstractmethod
    def create_collection(
        self,
        collection_name: str,
        embedding_size: int,
        drop_if_exists: bool = False,
    ) -> None:
        ...

    @abstractmethod
    def insert_one(
        self,
        collection_name: str,
        text: str,
        vector: List[float],
        metadata: Optional[Dict[str, Any]] = None,
        record_id: Optional[str] = None,
    ) -> None:
        ...

    @abstractmethod
    def insert_many(
        self,
        collection_name: str,
        texts: List[str],
        vectors: List[List[float]],
        metadatas: Optional[List[Optional[Dict[str, Any]]]] = None,
        record_ids: Optional[List[Optional[str]]] = None,
        batch_size: int = 50,
    ) -> None:
        ...

    @abstractmethod
    def search_by_vector(
        self,
        collection_name: str,
        query_vector: List[float],
        k: int = 10,
    ) -> List[Dict[str, Any]]:
        ...
```

شرح سطر‑بسطر مختصر:

- `from abc import ABC, abstractmethod`
    - بيستورد `ABC` عشان يعمل كلاس **مجرد** (ماينفعش تتعامل بيه مباشر)، و`abstractmethod` عشان يفرض إن أي subclass يطبّق الدوال دي.[^2_1]
- `from typing import ...`
    - Types للمساعدة في وضوح التواقيع (list, dict, optional…).[^2_1]
- `class VectorDBInterface(ABC):`
    - تعريف Interface عام لكل الـ Vector DBs (Qdrant، PGVector…)، بحيث أي implementation لازم يلتزم بنفس الواجهة دي.[^2_1]
- `connect / disconnect`
    - تركيبة عامة لأي DB: افتح connection وقفله (حتى لو implementation معينة مش محتاجة، تقدر تسيبها `pass`).[^2_1]
- دوال الـ collections (`collection_exists`, `list_collections`, `get_collection_info`, `delete_collection`, `create_collection`):
    - بتغطي الـ lifecycle الأساسي لأي collection: تعرف هل موجود، تجيب كل الموجود، تجيب info عن واحد، تمسح، تنشئ بembedding size محدد.[^2_1]
- `insert_one`
    - إدخال سجل واحد: بياخد النص، الـ vector، optional metadata (مثلاً document_id, page_number) و `record_id` لو حابب تتحكم في الـ id بنفسك.[^2_1]
- `insert_many`
    - نفس اللي فوق لكن batch: lists من النصوص، vectors، metadatas، record_ids، زائد `batch_size` للتحكم في حجم كل batch أثناء الإرسال للـ DB (لأسباب performance).[^2_1]
- `search_by_vector`
    - بتاخد query vector (embedding للسؤال) وترجع أقرب `k` سجلات في الـ collection.[^2_1]

لو حابب، في الرسالة الجاية نبص على `qdrant_db.py` الفعلي من الريبو ونشرحه سطر‑بسطر، بس احتاج منك واحد من الاتنين:

1. يا إمّا تبعت محتوى الملف `stores/vector_db/providers/qdrant_db.py` هنا عشان أشرح الكود الحقيقي سطر‑بسطر.

## 🎯 ملخص الملف

الملف ده **Factory Pattern** - نمط تصميم شهير في البرمجة:

**كيف يشتغل؟**

1. بتنشئ Factory واحد مرة واحدة، تديله الconfig
2. كل مرة عايز Vector DB، تنادي `factory.create("QDRANT")`
3. Factory يرجعلك instance جاهز ومعد بكل الإعدادات الصحيحة

**الفوايد:**
✅ **مركزية:** كل الإنشاءات في مكان واحد
✅ **سهولة الإضافة:** لو عايز تضيف Pinecone، تضيف `elif` واحد
✅ **Separation of concerns:** الكود اللي بيستخدم الdatabase مش محتاج يعرف تفاصيل الإنشاء

**مثال استخدام:**

```python
factory = VectorDBProviderFactory(config)
db = factory.create(config.VECTOR_DB_BACKEND)  # "QDRANT"
db.connect()
db.create_collection("my_docs", embedding_size=768)
```

class QdrantDBProvider(VectorDBInterface):
    
    async def insert_many_async(
        self,
        collection_name: str,
        texts: List[str],
        vectors: List[List[float]],
        metadata: Optional[List[Dict]] = None,
        batch_size: int = 50,
        max_concurrent: int = 3

        """
        إدخال بيانات متعددة بشكل async (أسرع).
        
        Args:

                'metadata': metadata[i:batch_end]
            })

                        }

from pydantic import field_validator, ConfigDict
from typing import Literal

class Settings(BaseSettings):

class QdrantDBBuilder:
    """Builder pattern لإنشاء Qdrant instance بسهولة."""
    
    def __init__(self):
        self._db_path: Optional[str] = None
        self._distance_method: str = "cosine"
        self._auto_connect: bool = True
        self._enable_metrics: bool = False
        self._cache_ttl: int = 60
    
    def with_path(self, path: str) -> 'QdrantDBBuilder':
        """تحديد مسار الdatabase."""
        self._db_path = path
        return self
    
    def with_distance(self, method: str) -> 'QdrantDBBuilder':
        """تحديد طريقة المسافة."""
        self._distance_method = method
        return self
    
    def auto_connect(self, enabled: bool = True) -> 'QdrantDBBuilder':
        """الاتصال أوتوماتيكيًا عند الإنشاء."""
        self._auto_connect = enabled
        return self
    
    def enable_metrics(self, enabled: bool = True) -> 'QdrantDBBuilder':
        """تفعيل تتبع الأداء."""
        self._enable_metrics = enabled
        return self
    
    def cache_ttl(self, seconds: int) -> 'QdrantDBBuilder':
        """مدة صلاحية الcache."""
        self._cache_ttl = seconds
        return self
    
    def build(self) -> QdrantDBProvider:
        """إنشاء الinstance."""
        if not self._db_path:
            raise ValueError("db_path مطلوب")
        
        db = QdrantDBProvider(
            db_path=self._db_path,
            distance_method=self._distance_method,
            enable_metrics=self._enable_metrics,
            cache_ttl=self._cache_ttl
        )
        
        if self._auto_connect:
            db.connect()
        
        return db

from enum import Enum
from dataclasses import dataclass
from datetime import datetime

class HealthStatus(Enum):
    """حالة صحة الdatabase."""
    HEALTHY = "healthy"
    DEGRADED = "degraded"
    UNHEALTHY = "unhealthy"

@dataclass
class HealthCheckResult:
    """نتيجة فحص الصحة."""
    status: HealthStatus
    timestamp: datetime
    details: Dict[str, Any]
    response_time_ms: float

class QdrantDBProvider(VectorDBInterface):
    
    def health_check(self) -> HealthCheckResult:
        """
        فحص صحة الdatabase والاتصال.
        
        Returns:
            HealthCheckResult مع التفاصيل الكاملة
        """
        start_time = time.time()
        details = {}
        status = HealthStatus.HEALTHY
        
        try:
            # 1. التحقق من الاتصال
            if self.client is None:
                return HealthCheckResult(
                    status=HealthStatus.UNHEALTHY,
                    timestamp=datetime.now(),
                    details={"error": "لا يوجد اتصال بالdatabase"},
                    response_time_ms=0
                )
            
            # 2. محاولة الحصول على قائمة الcollections
            try:
                collections = self.list_all_collections()
                details["collections_count"] = len(collections.collections)
                details["collections"] = [c.name for c in collections.collections]
            except Exception as e:
                status = HealthStatus.DEGRADED
                details["collections_error"] = str(e)
            
            # 3. قياس زمن الاستجابة
            response_time = (time.time() - start_time) * 1000  # ms
            details["response_time_ms"] = round(response_time, 2)
            
            # 4. تحديد الحالة بناءً على زمن الاستجابة
            if response_time > 5000:  # أكثر من 5 ثواني
                status = HealthStatus.UNHEALTHY
                details["warning"] = "زمن استجابة بطيء جدًا"
            elif response_time > 1000:  # أكثر من ثانية
                status = HealthStatus.DEGRADED
                details["warning"] = "زمن استجابة بطيء"
            
            # 5. معلومات إضافية
            details["client_type"] = "QdrantClient"
            details["db_path"] = self.db_path
            details["distance_method"] = str(self.distance_method)
            
            return HealthCheckResult(
                status=status,
                timestamp=datetime.now(),
                details=details,
                response_time_ms=response_time
            )
            
        except Exception as e:
            return HealthCheckResult(
                status=HealthStatus.UNHEALTHY,
                timestamp=datetime.now(),
                details={"error": str(e), "type": type(e).__name__},
                response_time_ms=(time.time() - start_time) * 1000

from pathlib import Path
import yaml
from typing import Optional

class VectorDBConfig:
    """
    إدارة إعدادات الVector DB من ملفات متعددة.
    """
    
    def __init__(self, env_file: str = ".env"):
        self.env_file = env_file
        self._config = {}
    
    @classmethod
    def from_yaml(cls, yaml_file: str) -> 'VectorDBConfig':
        """تحميل الإعدادات من YAML."""
        config = cls()
        
        with open(yaml_file, 'r', encoding='utf-8') as f:
            yaml_config = yaml.safe_load(f)
        
        config._config.update(yaml_config.get('vector_db', {}))
        return config
    
    @classmethod
    def from_dict(cls, config_dict: dict) -> 'VectorDBConfig':
        """تحميل من dictionary مباشرة."""
        config = cls()
        config._config.update(config_dict)
        return config
    
    def get(self, key: str, default: Any = None) -> Any:
        """الحصول على قيمة إعداد."""
        return self._config.get(key, default)
    
    def validate(self) -> bool:
        """التحقق من صحة الإعدادات."""
        required = ['backend', 'path', 'distance_method']
        
        for key in required:
            if key not in self._config:
                raise ValueError(f"الإعداد المطلوب '{key}' غير موجود")
        
        return True
    
    def to_dict(self) -> dict:
        """تحويل لdictionary."""
        return self._config.copy()
