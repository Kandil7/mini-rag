# اشرحلي الفيديو بالتفصيل مع الاكواد شرح مفصل سطر بسطر [https://youtu.be/V3swQKokJW8?si=mKo524wKn_1eCbp2](https://youtu.be/V3swQKokJW8?si=mKo524wKn_1eCbp2)

الفيديو بيكمّل مشروع mini-RAG لحد ما يبقى عندك Semantic Search حقيقي فوق تشانكات مخزّنة في Qdrant، لكن شرحه **سطر‑بسطر** فعليًا هيبقى أطول من نصّ الفيديو نفسه ومستحيل أكتبه بالكامل هنا بدون ما يتحول لكتاب.[^1_1][^1_2]

## 1. الفكرة العامة للحلقة

- بيربط كل ما تم بناؤه قبل كده (FastAPI + MongoDB + Qdrant + LLM factory) علشان يعمل:
    - Vector DB provider + factory.[^1_2]
    - NLP router جديد `/api/v1/nlp` فيه:
        - `/index/push/{project_id}`: يبني الـ collection ويعمل Index للـ chunks في Qdrant.[^1_2]
        - `/index/info/{project_id}`: يجيب معلومات عن الـ collection.[^1_2]
        - `/search/{project_id}`: يعمل semantic search بسؤال المستخدم.[^1_2]


## 2. أهم الملفات اللي تهمك في الفرع tut-009

من الريبو: `https://github.com/bakrianoo/mini-rag/tree/tut-009`[^1_1][^1_2]

أهم الملفات اللي بتنطبق عليها التعديلات اللي في الفيديو:

- `src/main.py`: تعريف الـ app وربط الـ routers + lifecycle (connect/disconnect).[^1_1][^1_2]
- `src/routes/nlp.py`: الرواتر الجديد للـ NLP (index, info, search).[^1_2]
- `src/controllers/nlp_controller.py`: كل لوجيك الـ Qdrant (create/delete collection, index, search).[^1_2]
- `src/stores/vector_db/*`: تعريف الـ VectorDB provider (Qdrant) والـ factory.[^1_2]

أنصحك تفتح الفرع `tut-009` وتحط كل ملف جنب الفيديو؛ كده تقدر تمشي سطر سطر بنفس ترتيب الشرح.[^1_1][^1_2]

## 3. ملخص منطق الأكواد (بالترتيب اللي في الفيديو)

### أ) ربط Vector DB بالـ app

في `main.py`:

- تعريف نوع جديد في الـ stores: `VectorDBProvider` يمثل الـ backend (مثلاً Qdrant).[^1_2]
- إعداد `app.vector_database_backend` ثم نداء `app.vector_database_backend.connect(...)` في startup و `disconnect()` في shutdown؛ زي ما حصل قبل كده مع Mongo.[^1_2]
- تغيير أسماء دوال الـ lifespan (من `startup_db_client` إلى `startup_span` وهكذا) ثم الرجوع مؤقتًا للأسلوب القديم لما حصلت مشكلة في `lifespan`.[^1_2]

الفكرة هنا:

- تحط abstraction للـ vector DB بحيث لو غيرت من Qdrant لغيره ما تغيّرش الكود في باقي النظام.[^1_2]


### ب) إنشاء NLP Router

في `src/routes/nlp.py`:[^1_2]

- `router = APIRouter(prefix="/api/v1/nlp", tags=["api-v1-nlp"])`.
- أول endpoint:
`POST /index/push/{project_id}`:
    - ياخد:
        - `project_id` من الـ path.
        - body اسمه `IndexPushRequest` فيه `project_id` و `do_reset: bool = False` (لإعادة بناء الـ collection من الصفر).[^1_2]
    - من داخل الفانكشن:
        - يجيب `request: Request` علشان يوصل لـ `app` ويستخرج clients (db, vector-db, llm).[^1_2]
        - يجيب `project_record` من `ProjectModel.get_project_by_id(project_id)`.[^1_2]
        - يجيب الـ chunks الخاصة بالمشروع (عن طريق `ChunkModel.paginate_by_project(...)` اللي اتبنَت في الفيديو).[^1_2]
        - ينشئ `NLPController` ويديله:
            - vector_db_client
            - embed_client
            - generation_client
            - logger …إلخ.[^1_2]
        - ينادي `nlp_controller.index_into_vector_database(project, chunks, do_reset=request_body.do_reset)`.[^1_2]
        - يرجّع `JSONResponse` فيها:
            - `signal` (رسالة نجاح)
            - `count` (عدد الـ chunks اللي اتعملها index).[^1_2]


### ج) تصميم `NLPController`

في `src/controllers/nlp_controller.py`:[^1_2]

- الكلاس يرث من `BaseController`.
- في `__init__`:
    - يستقبل:
        - `vector_db_client`
        - `embed_client`
        - `generation_client`
        - `logger` إلخ ويحفظهم كـ attributes.[^1_2]

الفانكشنات الأساسية:

1. `get_collection_name(project_id: str) -> str`
    - تبني اسم موحّد للـ collection مثل: `"collection_{project_id}".strip()`.[^1_2]
2. `delete_collection(project: Project)`
    - يحسب `collection_name` من `project.project_id`.
    - ينادي `self.vector_db_client.delete_collection(collection_name=collection_name)`.[^1_2]
3. `get_collection_info(project: Project)`
    - يبني `collection_name`.
    - ينادي `self.vector_db_client.collection_info(collection_name)` ويرجّع النتيجة بعد تحويلها لـ dict/JOSN بطريقة آمنة (باستخدام `json.dumps(..., default=lambda o: o.__dict__)` ثم `json.loads(...)`).[^1_2]
4. `index_into_vector_database(project: Project, chunks: list[DataChunk], do_reset: bool = False)`
منطق الخطوات:[^1_2]
    - لو `do_reset == True`:
        - ينادي `delete_collection(project)` في الأول.
    - يحوّل كل `chunk` إلى:
        - `texts = [chunk.chunk_text for chunk in chunks]`.
        - `metadatas = [chunk.chunk_meta for chunk in chunks]`.[^1_2]
    - يحسب `collection_name` من `project_id`.[^1_2]
    - ينادي على `self.vector_db_client.create_collection(collection_name, embedding_size, do_reset)`:
        - `embedding_size` جاي من `self.embed_client.embed_size`.[^1_2]
    - ينشئ embedding:
        - `embeddings = self.embed_client.embed(texts, doc_type="document")` (أو حسب API Cohere).[^1_2]
    - يضيف للـ vector DB:
        - في الفيديو اشتغل batched + record_ids:
            - يحسب `chunk_ids` كسلسلة أرقام متزايدة (باستخدام `id_idx` اللي بيتحرك مع كل batch).[^1_2]
            - ينادي `self.vector_db_client.insert_many(collection_name, embeddings, texts, metadatas, record_ids=chunk_ids)`.[^1_2]
    - يرجّع `True` لو نجح.[^1_2]

### د) Pagination للـ chunks

في `ChunkModel` (Mongo layer):[^1_2]

- إضافة دالة زي:
`get_project_chunks(project_id: str, page_number: int = 1, page_size: int = 50) -> list[DataChunk]`:
    - `skip = (page_number - 1) * page_size`.
    - `limit = page_size`.
    - `.find({"project_id": project_id}).skip(skip).limit(page_size)` ثم تحويل النتيجة لـ list من `DataChunk`.[^1_2]
- في الراوتر `index_push`:
    - حلقة `while has_records`:
        - تنادي دالة pagination لكل صفحة.
        - لو الليست فاضية: توقف.[^1_2]
        - تبعت صفحة التشانكات الحالية لـ `index_into_vector_database` وتكمّل.
    - يحافظ على counter بعدد الـ indexed chunks.[^1_2]


### هـ) Endpoint: Index Info

في `routes/nlp.py`:[^1_2]

- `GET /index/info/{project_id}` (في الفيديو خلاها `POST` لكن بدون body):
    - تجيب `project_record`.
    - تنشئ `NLPController`.
    - تنادي `get_collection_info(project_record)`.
    - تمرّر الناتج كـ JSON في response مع `signal="vector_db_collection_info"`.[^1_2]
- المشكلة اللي ظهرت: FastAPI مش قادر يحوّل object راجع من driver لجيسون.
    - الحل: استخدام `json.dumps(..., default=lambda o: getattr(o, "__dict__", str(o)))` ثم `json.loads(...)`.[^1_2]


### و) Endpoint: Search

في `NLPController.search_vector_database(...)`:[^1_2]

- المدخلات:
    - `project: Project`
    - `text: str` (سؤال المستخدم)
    - `limit: int` عدد النتائج.[^1_2]
- الخطوات:
    - يحوّل الـ query إلى embedding:
        - `query_vec = self.embed_client.embed_text(text, doc_type="query")[^1_0]`.[^1_2]
    - ينادي:
        - `self.vector_db_client.search_by_vector(collection_name, vector=query_vec, limit=limit)`.[^1_2]
    - لو مفيش فيكتور/خطأ: يرجّع False.
    - يحوّل النتيجة لـ JSON-safe dict بنفس حيلة `json.dumps/loads`.[^1_2]

في `routes/nlp.py`:

- تعريف `SearchRequest` Pydantic model فيها:
    - `text: str`
    - `limit: int = 10`.[^1_2]
- Endpoint:
    - `POST /search/{project_id}`
    - يجمع:
        - `project_record`
        - `nlp_controller`
    - ينادي:
        - `result = nlp_controller.search_vector_database(project_record, request.text, request.limit)`.[^1_2]
    - لو `not result`: يرجّع 400 مع `signal="vector_db_search_error"`.
    - غير كده:
        - `signal="vector_db_search_success"`
        - `data=result`.[^1_2]

### 2. ملف `src/stores/llm/LLMInterface.py`

```python
from abc import ABC, abstractmethod
from typing import List

class LLMInterface(ABC):
    
    @abstractmethod
    def generate_text(self, prompt: str, **kwargs) -> str:
        pass
    
    @abstractmethod
    def embed_text(self, text: str, doc_type: str = "document") -> List[float]:
        pass
    
    @abstractmethod
    def embed(self, texts: List[str], doc_type: str = "document") -> List[List[float]]:
        pass
```

**الشرح سطر بسطر:**

- **سطر 1**: استيراد `ABC` (Abstract Base Class) و `abstractmethod` لإنشاء interface
- **سطر 2**: استيراد `List` من typing للـ type hints
- **سطر 4**: تعريف الـ Interface class - أي provider لازم ينفّذ الـ methods دي
- **سطر 6-8**: abstract method اسمه `generate_text` - بياخد prompt وبيرجع نص مُولّد
    - `prompt: str`: النص اللي هتبعته للـ LLM
    - `**kwargs`: أي parameters إضافية (temperature, max_tokens, إلخ)
    - `-> str`: بيرجع string
- **سطر 10-12**: `embed_text` - لتحويل نص واحد لـ embedding vector
    - `text: str`: النص المطلوب تحويله
    - `doc_type`: نوع النص (document أو query) - بعض الـ models بتفرّق في الـ embedding حسب النوع
    - `-> List[float]`: بيرجع list من أرقام (vector)
- **سطر 14-16**: `embed` - لتحويل multiple texts لـ embeddings دفعة واحدة (batch)
    - `texts: List[str]`: list من النصوص
    - `-> List[List[float]]`: بيرجع list من vectors

**الهدف**: ده الـ contract اللي أي LLM provider لازم يلتزم بيه

### 7. ملف `src/stores/vectordb/providers/QdrantDBProvider.py`

```python
from models.db_schemes import RetrievedDocument

def search_by_vector(self, collection_name: str, vector: list, limit: int = 5):
    
    results = self.client.search(
        collection_name=collection_name,
        query_vector=vector,
        limit=limit
    )
    
    if not results or len(results) == 0:
        return None
    
    return [
        RetrievedDocument(**{
            "score": result.score,
            "text": result.payload["text"],
        })
        for result in results
    ]
```

**الشرح سطر بسطر:**

- **سطر 13-18**: **list comprehension** بتحوّل كل result من Qdrant لـ `RetrievedDocument`:
    - `result.score`: درجة التشابه
    - `result.payload["text"]`: النص الأصلي
    - **`**{...}`**: dictionary unpacking لإنشاء Pydantic model

```python
import requests

class RAGChatbot:
    def __init__(self, base_url, project_id):
        self.base_url = base_url
        self.project_id = project_id
        self.chat_history = []
    
    def ask(self, question):
        """طرح سؤال مع الاحتفاظ بالـ context"""
        response = requests.post(
            f"{self.base_url}/nlp/index/answer/{self.project_id}",
            json={
                "text": question,
                "limit": 5
            }
        )
        
        result = response.json()
        
        if result["signal"] == "rag_answer_success":
            # حفظ السؤال والإجابة في الذاكرة
            self.chat_history.append({
                "question": question,
                "answer": result["answer"]
            })
            return result["answer"]
        else:
            return "عذراً، لم أتمكن من إيجاد إجابة."
    
    def get_conversation_history(self):
        """الحصول على تاريخ المحادثة"""
        return self.chat_history

# الاستخدام
bot = RAGChatbot("http://localhost:8000", "my_project")

# محادثة طبيعية

print(f"الإجابة 1: {answer1}")

print(f"الإجابة 2: {answer2}")

answer3 = bot.ask("كيف أبدأ في تعلمه؟")
print(f"الإجابة 3: {answer3}")

# عرض تاريخ المحادثة
for idx, conv in enumerate(bot.get_conversation_history(), 1):
```

```python
def merge_results(self, vector_results, keyword_results, k=60):
    """Reciprocal Rank Fusion"""
    scores = {}
    
    # حساب scores من vector search
    for rank, doc in enumerate(vector_results, 1):
        doc_id = doc.text  # استخدم identifier مناسب
        scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank)
    
    # إضافة scores من keyword search
    for rank, doc in enumerate(keyword_results, 1):
        doc_id = doc.text
        scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank)
    
    # ترتيب النتائج
    sorted_docs = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    
    # إرجاع المستندات المرتبة
    return [doc for doc_id, score in sorted_docs]
```

```python
class RAGEvaluator:
    """تقييم جودة نظام RAG"""
    
    def __init__(self, nlp_controller):
        self.controller = nlp_controller
    
    def evaluate_retrieval(self, test_cases):
        """تقييم مرحلة الـ Retrieval"""
        results = {
            "precision": [],
            "recall": [],
            "mrr": []  # Mean Reciprocal Rank
        }
        
        for case in test_cases:
            query = case["query"]
            relevant_docs = set(case["relevant_doc_ids"])
            
            # البحث
            retrieved = self.controller.search_vector_db_collection(
                project=case["project"],
                text=query,
                limit=10
            )
            
            retrieved_ids = {doc.id for doc in retrieved}
            
            # حساب Precision & Recall
            tp = len(relevant_docs & retrieved_ids)
            precision = tp / len(retrieved_ids) if retrieved_ids else 0
            recall = tp / len(relevant_docs) if relevant_docs else 0
            
            results["precision"].append(precision)
            results["recall"].append(recall)
            
            # حساب MRR
            for rank, doc in enumerate(retrieved, 1):
                if doc.id in relevant_docs:
                    results["mrr"].append(1 / rank)
                    break
            else:
                results["mrr"].append(0)
        
        return {
            "avg_precision": sum(results["precision"]) / len(results["precision"]),
            "avg_recall": sum(results["recall"]) / len(results["recall"]),
            "avg_mrr": sum(results["mrr"]) / len(results["mrr"])
        }
    
    def evaluate_generation(self, test_cases):
        """تقييم جودة الإجابات المولدة"""
        from rouge_score import rouge_scorer
        
        scorer = rouge_scorer.RougeScorer(['rouge1', 'rouge2', 'rougeL'], use_stemmer=True)
        results = []
        
        for case in test_cases:
            # توليد إجابة
            answer, _, _ = self.controller.answer_rag_question(
                project=case["project"],
                query=case["query"],
                limit=10
            )
            
            # مقارنة مع الإجابة المرجعية
            scores = scorer.score(case["reference_answer"], answer)
            results.append(scores)
        
        return results
```

```python
from functools import lru_cache
import hashlib

class CachedNLPController(NLPController):
    """NLP Controller مع caching للإجابات"""
    
    def __init__(self, *args, cache_ttl=3600, **kwargs):
        super().__init__(*args, **kwargs)
        self.cache = {}
        self.cache_ttl = cache_ttl
    
    def _generate_cache_key(self, project_id, query):
        """توليد مفتاح فريد للـ cache"""
        key_string = f"{project_id}:{query}"
        return hashlib.md5(key_string.encode()).hexdigest()
    
    def answer_rag_question_cached(self, project, query, limit=10):
        """RAG مع caching"""
        import time
        
        cache_key = self._generate_cache_key(project.id, query)
        
        # التحقق من الـ cache
        if cache_key in self.cache:
            cached_data, timestamp = self.cache[cache_key]
            
            # التحقق من انتهاء الصلاحية
            if time.time() - timestamp < self.cache_ttl:
                print("📦 Retrieved from cache")
                return cached_data
        
        # إذا لم يوجد في cache، نفذ RAG
        print("🔄 Generating new answer...")
        result = self.answer_rag_question(project, query, limit)
        
        # حفظ في cache
        self.cache[cache_key] = (result, time.time())
        
        return result
    
    def clear_cache(self, project_id=None):
        """مسح الـ cache"""
        if project_id:
            # مسح cache لمشروع معين
            keys_to_delete = [
                k for k in self.cache.keys()
                if k.startswith(self._generate_cache_key(project_id, "")[:8])
            ]
            for key in keys_to_delete:
                del self.cache[key]
        else:
            # مسح كل الـ cache
            self.cache.clear()
```

```python
    @validator('text')
    def validate_text(cls, v):
        """التحقق من النص"""
        # إزالة HTML tags
        v = re.sub(r'<[^>]+>', '', v)
        
        # إزالة SQL injection attempts
        dangerous_patterns = [
            r'(\bSELECT\b|\bDROP\b|\bINSERT\b|\bUPDATE\b|\bDELETE\b)',
            r'(\-\-|\/\*|\*\/|;)',
        ]
        for pattern in dangerous_patterns:
            if re.search(pattern, v, re.IGNORECASE):
                raise ValueError("Invalid input detected")
        
        # إزالة مسافات زائدة
        v = ' '.join(v.split())
        
        return v
    
    @validator('limit')
    def validate_limit(cls, v):
        """التأكد من عدم طلب عدد كبير جداً"""
        if v > 50:
            raise ValueError("Limit cannot exceed 50")
```

```python
from fastapi import HTTPException
from collections import defaultdict
from datetime import datetime, timedelta

class RateLimiter:
    """حماية من الاستخدام المفرط"""
    
    def __init__(self, max_requests=10, window_seconds=60):
        self.max_requests = max_requests
        self.window_seconds = window_seconds
        self.requests = defaultdict(list)
    
    def is_allowed(self, client_id: str) -> bool:
        """التحقق من السماح بالطلب"""
        now = datetime.now()
        
        # مسح الطلبات القديمة
        cutoff = now - timedelta(seconds=self.window_seconds)
        self.requests[client_id] = [
            req_time for req_time in self.requests[client_id]
            if req_time > cutoff
        ]
        
        # التحقق من العدد
        if len(self.requests[client_id]) >= self.max_requests:
            return False
        
        # إضافة الطلب الحالي
        self.requests[client_id].append(now)
        return True
    
    def get_remaining(self, client_id: str) -> int:
        """الحصول على عدد الطلبات المتبقية"""
        now = datetime.now()
        cutoff = now - timedelta(seconds=self.window_seconds)
        recent_requests = [
            req_time for req_time in self.requests[client_id]
            if req_time > cutoff
        ]
        return max(0, self.max_requests - len(recent_requests))

# Global rate limiter
```

### **1. تحسين Chunking Strategy**

```python
def intelligent_chunking(text, chunk_size=512, overlap=50):
    """تقسيم ذكي يحترم حدود الجمل"""
    import nltk
    
    # تقسيم إلى جمل
    sentences = nltk.sent_tokenize(text)
    
    chunks = []
    current_chunk = []
    current_length = 0
    
    for sentence in sentences:
        sentence_length = len(sentence)
        
        # إذا الجملة أطول من chunk_size، قسمها
        if sentence_length > chunk_size:
            # حفظ الـ chunk الحالي
            if current_chunk:
                chunks.append(' '.join(current_chunk))
            
            # تقسيم الجملة الطويلة
            words = sentence.split()
            temp_chunk = []
            temp_length = 0
            
            for word in words:
                if temp_length + len(word) > chunk_size:
                    chunks.append(' '.join(temp_chunk))
                    temp_chunk = temp_chunk[-overlap:] if overlap > 0 else []
                    temp_length = sum(len(w) for w in temp_chunk)
                
                temp_chunk.append(word)
                temp_length += len(word) + 1
            
            if temp_chunk:
                current_chunk = temp_chunk
                current_length = temp_length
        
        # جملة عادية
        elif current_length + sentence_length > chunk_size:
            # حفظ الـ chunk الحالي
            chunks.append(' '.join(current_chunk))
            
            # بداية chunk جديد مع overlap
            if overlap > 0:
                overlap_sentences = current_chunk[-overlap:]
                current_chunk = overlap_sentences + [sentence]
                current_length = sum(len(s) for s in current_chunk)
            else:
                current_chunk = [sentence]
                current_length = sentence_length
        else:
            current_chunk.append(sentence)
            current_length += sentence_length + 1
    
    # إضافة الـ chunk الأخير
    if current_chunk:
        chunks.append(' '.join(current_chunk))
    
    return chunks
```

```python
class TemplateParser:
    def __init__(self, language: str = None, default_language='en'):
        self.current_path = os.path.dirname(os.path.abspath(__file__))
        self.default_language = default_language
        self.language = None
        
        # ✅ إضافة cache للـ modules
        self._module_cache = {}
        
        self.set_language(language)
    
    def _load_module(self, language: str, group: str):
        """تحميل module مع caching"""
        cache_key = f"{language}.{group}"
        
        # ✅ التحقق من الـ cache أولاً
        if cache_key in self._module_cache:
            return self._module_cache[cache_key]
        
        try:
            module = __import__(
                f"stores.llm.templates.locales.{language}.{group}",
                fromlist=[group]
            )
            # ✅ حفظ في الـ cache
            self._module_cache[cache_key] = module
            return module
        except ImportError as e:
            # ✅ معالجة أفضل للأخطاء
            logging.error(f"Failed to load template module: {cache_key} - {e}")
            return None
    
    def get(self, group: str, key: str, vars: dict = {}):
        """الحصول على template مع error handling محسن"""
        if not group or not key:
            return None
        
        # محاولة تحميل من اللغة الحالية
        module = self._load_module(self.language, group)
        
        # إذا فشل، جرب اللغة الافتراضية
        if not module:
            module = self._load_module(self.default_language, group)
        
        if not module:
            # ✅ لو فشل كل شيء، ارجع fallback template
            return self._get_fallback_template(key, vars)
        
        try:
            key_attribute = getattr(module, key)
            return key_attribute.substitute(vars)
        except (AttributeError, KeyError) as e:
            logging.error(f"Template error: {group}.{key} - {e}")
            return self._get_fallback_template(key, vars)
    
    def _get_fallback_template(self, key: str, vars: dict):
        """template احتياطي عند الفشل"""
        fallback_templates = {
            "system_prompt": "You are a helpful assistant.",
            "document_prompt": "Document: ${chunk_text}",
            "footer_prompt": "Please provide an answer based on the above."
        }
        
        template = Template(fallback_templates.get(key, ""))
        try:
            return template.safe_substitute(vars)  # ✅ safe_substitute بدلاً من substitute
        except Exception:
            return ""
```

```python
    footer_prompt = self.template_parser.get("rag", "footer_prompt")
    
    system_tokens = len(encoding.encode(system_prompt))
    footer_tokens = len(encoding.encode(footer_prompt))
    query_tokens = len(encoding.encode(query))
    
    # ✅ الـ tokens المتاحة للمستندات
    available_tokens = max_context_tokens - system_tokens - footer_tokens - query_tokens - 500  # buffer
    
    # ✅ إضافة المستندات حتى نصل للحد الأقصى
    selected_documents = []
    current_tokens = 0
    
    for idx, doc in enumerate(retrieved_documents):
        doc_template = self.template_parser.get("rag", "document_prompt", {
            "doc_num": idx + 1,
            "chunk_text": doc.text,
        })
        doc_tokens = len(encoding.encode(doc_template))
        
        # ✅ التحقق من المساحة المتاحة
        if current_tokens + doc_tokens > available_tokens:
            # إذا كان المستند الأول أكبر من المساحة، نقتطعه
            if idx == 0:
                # ✅ truncate للمستند الأول بذكاء
                max_doc_tokens = available_tokens - 100  # buffer
                truncated_text = self._truncate_text(doc.text, max_doc_tokens, encoding)
                doc_template = self.template_parser.get("rag", "document_prompt", {
                    "doc_num": 1,
                    "chunk_text": truncated_text + "\n[...تم الاختصار]",
                })
                selected_documents.append(doc_template)
            break
        
        selected_documents.append(doc_template)
        current_tokens += doc_tokens
    
    # ✅ التحذير إذا لم نستخدم كل المستندات
    if len(selected_documents) < len(retrieved_documents):
        logging.warning(
            f"Used {len(selected_documents)}/{len(retrieved_documents)} documents "
            f"due to context limit ({current_tokens}/{available_tokens} tokens)"
        )
    
    documents_prompts = "\n".join(selected_documents)
    
    # ... باقي الكود
    
def _truncate_text(self, text: str, max_tokens: int, encoding) -> str:
    """اقتطاع النص بذكاء عند الجملة"""
    tokens = encoding.encode(text)
    
    if len(tokens) <= max_tokens:
        return text
    
    # اقتطاع عند max_tokens
    truncated_tokens = tokens[:max_tokens]
    truncated_text = encoding.decode(truncated_tokens)
    
    # ✅ محاولة الاقتطاع عند آخر جملة كاملة
    last_period = truncated_text.rfind('.')
    last_question = truncated_text.rfind('?')
    last_exclamation = truncated_text.rfind('!')
    
    # العربية
    last_arabic_period = truncated_text.rfind('。')
    
    cut_point = max(last_period, last_question, last_exclamation, last_arabic_period)
    
    if cut_point > len(truncated_text) * 0.7:  # إذا النقطة في آخر 30%
        return truncated_text[:cut_point + 1]
    
    return truncated_text
```

```python
class DocumentRetriever:
    """مسؤول فقط عن استرجاع المستندات"""
    
    def __init__(self, vectordb_client, embedding_client):
        self.vectordb_client = vectordb_client
        self.embedding_client = embedding_client
    
    def retrieve(
        self, 
        collection_name: str, 
        query: str, 
        limit: int = 10,
        filters: Optional[dict] = None,
        rerank: bool = True
    ) -> List[RetrievedDocument]:
        """استرجاع المستندات مع خيارات متقدمة"""
        
        # Vector search
        query_vector = self.embedding_client.embed_text(query)
        results = self.vectordb_client.search_by_vector(
            collection_name=collection_name,
            vector=query_vector,
            limit=limit * 2 if rerank else limit
        )
        
        if not results:
            return []
        
        # Apply filters
        if filters:
            results = self._apply_filters(results, filters)
        
        # Re-ranking
        if rerank:
            results = self._rerank(query, results, limit)
        
        return results
    
    def _apply_filters(self, documents, filters):

        filtered = []
        for doc in documents:
            match = True
            for key, value in filters.items():
                if doc.metadata.get(key) != value:
                    match = False
                    break
            if match:
                filtered.append(doc)
        return filtered
    
    def _rerank(self, query, documents, top_k):
        """Re-ranking مع cross-encoder"""
        # TODO: تطبيق re-ranking
        return documents[:top_k]

        self,

    ) -> dict:

            })

        return "\n".join(prompts), len(selected)

        self,

        documents = self.retriever.retrieve(
            collection_name=collection_name,
            query=query,
            limit=limit,
            filters=filters
        )
        
        if not documents:
            return {
                "success": False,
                "error": "No relevant documents found"
            }
        
        # Step 2: Build prompt
        self.logger.info(f"Building prompt with {len(documents)} documents")
        prompt_data = self.prompt_builder.build_rag_prompt(
            query=query,
            documents=documents
        )
        
        # Step 3: Generate
        self.logger.info("Generating answer...")
        result = self.answer_generator.generate(
            system_prompt=prompt_data["system_prompt"],
            user_prompt=prompt_data["user_prompt"],
            temperature=temperature
        )
        
        # Step 4: Prepare response
        return {
            "success": True,
            "answer": result["answer"],
            "documents": documents,
            "documents_used": prompt_data["documents_used"],
            "estimated_tokens": prompt_data["estimated_tokens"]
        }
```

    """معالجة وتحسين الاستعلامات"""
    
    def __init__(self, language="ar"):
        self.language = language
        self.synonym_dict = self._load_synonyms()
        self.spell_checker = self._init_spell_checker()
    
    def process_query(self, query: str) -> dict:
        """معالجة شاملة للاستعلام"""
        
        # ✅ Step 1: تنظيف أساسي
        cleaned = self._clean_query(query)
        
        # ✅ Step 2: تصحيح إملائي
        corrected, corrections = self._spell_check(cleaned)
        
        # ✅ Step 3: تحليل نوع السؤال
        query_type = self._classify_question(corrected)
        
        # ✅ Step 4: توسيع بالمرادفات
        expanded = self._expand_with_synonyms(corrected)
        
        # ✅ Step 5: استخراج الكلمات المفتاحية
        keywords = self._extract_keywords(corrected)
        
        return {
            "original": query,
            "cleaned": cleaned,
            "corrected": corrected,
            "expanded": expanded,
            "query_type": query_type,
            "keywords": keywords,
            "corrections_made": corrections
        }
    
    def _clean_query(self, query: str) -> str:
        """تنظيف الاستعلام"""
        import re
        
        # إزالة مسافات زائدة
        query = ' '.join(query.split())
        
        # إزالة علامات غير ضرورية
        query = re.sub(r'[^\w\s\u0600-\u06FF؟?!]', '', query)
        
        return query.strip()
    
    def _spell_check(self, query: str) -> tuple:
        """تصحيح إملائي بسيط"""
        corrections = []
        
        # قاموس أخطاء شائعة
        common_errors = {
            "الذكاء الصناعي": "الذكاء الاصطناعي",
            "machien learning": "machine learning",
            "artifical": "artificial",
        }
        
        corrected = query
        for wrong, correct in common_errors.items():
            if wrong in corrected.lower():
                corrected = corrected.replace(wrong, correct)
                corrections.append({
                    "original": wrong,
                    "corrected": correct
                })
        
        return corrected, corrections
    
    def _classify_question(self, query: str) -> str:
        """تصنيف نوع السؤال"""
        query_lower = query.lower()
        
        # أسئلة تعريفية
        if any(word in query_lower for word in ["ما هو", "ما هي", "what is", "define"]):
            return "definition"
        
        # أسئلة كيفية
        if any(word in query_lower for word in ["كيف", "how to", "how can"]):
            return "how_to"
        
        # أسئلة مقارنة
        if any(word in query_lower for word in ["فرق", "difference", "compare", "vs"]):
            return "comparison"
        
        # أسئلة قائمة
        if any(word in query_lower for word in ["أنواع", "أمثلة", "list", "types", "examples"]):
            return "list"
        
        # أسئلة سببية
        if any(word in query_lower for word in ["لماذا", "why", "reason"]):
            return "why"
        
        return "general"
    
    def _expand_with_synonyms(self, query: str) -> str:
        """توسيع بالمرادفات"""
        words = query.split()
        expanded_words = []
        
        for word in words:
            expanded_words.append(word)
            
            # إضافة مرادفات
            if word.lower() in self.synonym_dict:
                synonyms = self.synonym_dict[word.lower()]
                expanded_words.extend(synonyms[:2])  # ✅ فقط أول 2 مرادفات
        
        return ' '.join(expanded_words)
    
    def _extract_keywords(self, query: str) -> list:
        """استخراج كلمات مفتاحية"""
        import re
        
        # إزالة stop words
        stop_words = {
            "ar": ["هو", "هي", "في", "من", "إلى", "على", "ما", "الذي"],
            "en": ["is", "are", "the", "a", "an", "in", "on", "at", "to"]
        }
        
        words = re.findall(r'\w+', query.lower())
        keywords = [
            w for w in words 
            if w not in stop_words.get(self.language, [])
            and len(w) > 2
        ]
        
        return keywords
